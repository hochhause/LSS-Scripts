# Wunschbild — manuelle Anleitung

Stand 2026-10-09, aus der Sicherung des Planers (Wunschbild v0.66.1). Feuerwache nur Profil „standard". Lehrgänge sind als kostenlos gerechnet.

**Woher die Preise kommen:** Fahrzeuge von der Kaufseite einer eigenen Wache je Typ (09.10.2026). Ausbauten, Ausbaustufen und Gebäude aus der LSS-Manager-API; jeder Ausbaupreis, der im Spiel noch sichtbar war (an Feuer-, Rettungs- und Polizeiwachen; gebaute Ausbauten zeigen keinen Preis mehr), stimmte mit ihr überein. Bei sieben Fahrzeugen weicht die API vom Spiel ab — dort gilt der Spielpreis. Für Gebäudearten ohne eigene Wache ist alles aus der API und so markiert.
